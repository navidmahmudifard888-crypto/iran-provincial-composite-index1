# Validation

## External convergent check

Criterion: **2023 Subnational Human Development Index (SHDI)** from Global Data Lab.

Matched provinces: **29**. Tehran and Alborz are not separately represented in the external file because the source aggregates them together.

Current associations:

| Metric | Value | p-value |
|---|---:|---:|
| Pearson | -0.176 | 0.362 |
| Spearman | -0.157 | 0.417 |
| Kendall | -0.124 | 0.348 |

The association is weak and non-significant. SHDI also overlaps conceptually with several model dimensions, so this is reported as **convergent evidence**, not independent validation.

## What is not claimed

The project does **not** claim external validation, causal validation, predictive validation or a clean holdout test.
