# Portfolio visuals

These figures are rendered from the frozen V2.1 outputs. CSV model outputs remain the numerical source of truth.

- `ranking.png` — final provincial ranking
- `temporal_robustness.png` — temporal robustness
- `monte_carlo_stability.png` — local Monte Carlo rank intervals
- `province_data_quality.png` — province-level data quality

The interactive geographic map is generated by `scripts/visualization_suite.py` when its external boundary source is supplied. The original input workbook and row-level transformed observations are omitted from this public-ready archive pending source-by-source redistribution review; see `DATA_LICENSE_REVIEW.md`.
