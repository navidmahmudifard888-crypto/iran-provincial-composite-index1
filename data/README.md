# Data directory

The public-ready package retains only data files judged suitable for project diagnostics and documentation at this stage. Original input and row-level transformed observations are excluded pending source-by-source rights review. The external validation file and aggregated model outputs are retained for portfolio inspection; their original source and usage terms should still be cited as documented where known.

To run the pipeline locally, supply an input workbook whose source terms permit the intended use. See `DATA_LICENSE_REVIEW.md`.
