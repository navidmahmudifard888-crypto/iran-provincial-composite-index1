# Limitations

1. **Provenance:** active series remain conditional because complete row-level source URLs and extraction records are not available in the supplied workbook metadata.
2. **Weighting:** domain weights are design assumptions and can materially change rankings when emphasized or removed.
3. **Normalization:** within-year Min-Max is appropriate for relative-standing interpretation but is not an absolute temporal level measure.
4. **Temporal heterogeneity:** indicators originate from different years and are combined through explicit recency weighting; this is a modeling choice.
5. **Population denominators:** selected count indicators use substantively meaningful population denominators, but some fallback denominators may come from a nearby year when same-year population is unavailable.
6. **Validation:** SHDI provides only convergent evidence and is not independent enough to support a strong validation claim.
7. **Construct coverage:** the final 33-series active set is a curated subset of the 151-series registry; excluded indicators can change construct coverage even when exclusion is methodologically defensible.
